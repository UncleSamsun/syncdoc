# 서버 비교 검증 요구

회사 테스트 서버의 게시본 비교 인수 시험용 문서다. main 제품 요구에 포함하지 않는다.

## REQ-901 본문 변화 검증

**대상:** 서버 비교 검증 프로젝트

**조건:** 같은 제목의 요구 본문만 변경한다.

**기대 동작:** 원문 변경으로 표시한다. 기준 본문은 버전 B다.

**인수 기준:** REQ-901의 원문 변경과 TASK-901 재검토 후보를 표시한다.

**예외:** 비교 자료가 없는 과거 게시본은 미확인이다.

**근거:** TASK-017 회사 서버 인수 시험.
