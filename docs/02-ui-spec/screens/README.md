# 화면 정의 페이지

이 폴더는 UI 명세의 **시각 참조**다. 구현 기준의 정본은 [공통 UI 규칙](../ui-conventions.md)과 [화면 명세](../ui-screens.md)이며, 두 문서와 이 페이지가 어긋나면 두 문서를 따른다.

## 내용

| 파일 | 설명 |
|---|---|
| `index.html` | UI-000 ~ UI-012 화면 정의, 토큰, 공통 컴포넌트를 한 페이지에 모은 목업 |
| `fonts/PretendardVariable.woff2` | Pretendard v1.3.9 가변 서체 (SIL OFL). `index.html`이 상대 경로로 참조한다 |

## 보는 방법

`index.html`을 브라우저에서 그대로 연다. 빌드 도구와 네트워크가 필요 없다. 서체를 같은 폴더에서 읽으므로 어느 환경에서 열어도 같은 글자로 보인다.

## 주의

- 페이지의 모든 수치·문서 목록·Issue 번호는 fixture 샘플이다. 실제 GitHub 조회 결과가 아니다.
- 실행되는 React 앱이 아니다. `frontend/`는 아직 없다.
- 페이지에서 동작하는 것은 문서 트리의 폴더 접기뿐이다(`<details>`). 나머지 조작은 반응하지 않는다.
- 명세를 고칠 때 이 페이지도 함께 고친다. 페이지만 고치고 명세를 두지 않는다.
