# GitHub 협업 프로세스

2026-09-09 사용자 정정과 확정을 반영해 상세 내용을 공통 규칙으로 이관했다.

- [GitHub 협업 규칙](../../rules/github-collaboration.md): main/dev/작업 브랜치, Issue·Project, 담당 영역별 리뷰, 완료·취소·릴리스.
- [SDD 역할과 승인 범위](../../rules/sdd-workflow.md)
- [ID와 문서 참조](../../rules/identity-and-references.md)

이전 main 단일 통합 브랜치와 팀 전체 타인 리뷰 필수 제안은 대체되었다. 세부 운영은 위 정본에서만 관리한다. 릴리스는 담당자가 선택한 시점의 dev 전체로 확정했다. GitHub 실제 설정은 아직 수행하지 않았다.
