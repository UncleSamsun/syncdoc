# 규칙 fixture

정의 파일과 어긋난 표. 주석은 어디가 다른지 적어 둔 것이며 검사 대상이 아니다.

## 3. 문서 종류와 필수 내용

| type | 문서 종류 | 적용 조건 | 필수 내용 |
|---|---|---|---|
| `prd-requirements` | 기능·품질 요구 | 모든 프로젝트 | 요구 ID, 예외, 인수 기준 |
| `ui-screens` | 화면 명세 | 사용자 화면이 있으면 | 화면 ID, 연결 요구, 검증 |
| `tasks` | 작업 정의 | 구현 대상으로 정한 기능 | 작업 ID, 근거, 선행, 산출물, 검증, 완료 |
| `note` | 메모 | 언제나 | 내용 |

첫 행은 `근거`가 빠졌고, 마지막 행 `note`는 정의 파일에 없다.

## 5. 필수 내용 표기

### 라벨 이름 공간

| type | 허용하는 굵은 라벨 |
|---|---|
| `prd-requirements` | 예외, 인수 기준, 근거 |
| `ui-screens` | 연결 요구, 검증 |
| `tasks` | 근거, 선행, 산출물, 검증, 완료, 담당자 |

`tasks`에 정의 파일에 없는 `담당자`가 있다.

| type | 검사 단위 | 검사기가 요구하는 라벨 |
|---|---|---|
| `prd-requirements` | `## REQ-NNN` 섹션마다 | `예외`, `인수 기준`, `근거` |
| `ui-screens` | `## UI-NNN` 섹션마다 | `연결 요구` |
| `tasks` | `## TASK-NNN` 섹션마다 | `근거`, `선행`, `산출물`, `검증`, `완료` |

`ui-screens`에 `검증`이 빠졌다.
